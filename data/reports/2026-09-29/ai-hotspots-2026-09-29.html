推荐选题

选题 01｜A+

一个 Agent 为什么既要会点鼠标，也要懂 API：Holo4 暴露了自动化的真正难题

受众：AI 自媒体、Agent 开发者、RPA 与企业自动化团队、效率工具博主

角度：从单模型在 GUI、代码、MCP 与 API 之间路由切入，解释业务自动化最难的不是会操作，而是选择正确接口、保持跨界面状态一致并完成可验证验收。

结构：1. 只会点击或只会 API 的局限；2. Holo4 的多界面主张；3. 路由为何是推理任务；4. 状态漂移与权限风险；5. 设计一个跨浏览器、表格和 API 的实测；6. 成功率、成本与人工接管指标。

风险：基准来自厂商且 harness、subset 不完全一致；不要把开源权重写成训练数据与完整训练栈全部开放。

选题 02｜A

Claude Sonnet 5.5 没降单价，为什么 Anthropic 仍称单任务最多便宜 30%？

受众：AI 工具测评博主、内容团队、开发者、企业采购与 FinOps

角度：把 token 单价和单任务总成本分开，设计同一份文章、幻灯片或代码任务的速度、token、工具调用、返工和成功率对照。

结构：1. 官方价格；2. 速度与 token 主张；3. 单价不等于任务成本；4. 统一提示词与素材；5. 记录失败重试；6. 给出选型表。

风险：30% 为厂商典型任务口径；不同 effort、缓存、工具和任务类型不可混比。
