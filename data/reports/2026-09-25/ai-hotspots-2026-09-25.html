推荐选题

选题 01｜A+

AI 眼镜真正的拐点不是硬件：网页、连接器和 Agent 都能上镜了

受众：AI 产品关注者、创作者、独立开发者、智能硬件与消费科技读者

角度：把 Connect 2026 拆成一条完整链路：Muse 看见现实、语音持续协作、连接器完成交易；开发者又能用移动 App、Web App 与 API 把服务搬上眼镜。

结构：1. 为什么不是又一场硬件发布；2. 看见后能做什么；3. 三条开发路径；4. WebMCP 与连接器；5. 创作者的现场工作流；6. 未上线与隐私边界。

风险：Muse 上眼镜仍属未来数月计划，开发更新自 9 月 30 日起推送，WebMCP 是开发者预览；必须把演示、预览与已可用能力分开。

选题 02｜A

Slack 里的 AI 到底该用谁的权限？Claude 给出了一种分层答案

受众：企业协作用户、AI Agent 开发者、IT 管理员、效率类创作者

角度：用 Claude Tag 的个人与共享连接器解释三层边界：谁发起、谁授权、谁能看结果，再比较审核模式与无人值守任务。

结构：1. 频道 Agent 的权限悖论；2. 个人连接器；3. 共享连接器；4. 发布前审核；5. 日志与责任；6. 团队配置清单。

风险：Claude Tag 仍为 beta，个人连接器先在 Team 推送且不支持无人值守；不可泛化为 Slack 或所有 Agent 的通用机制。

选题 03｜A

950 个 Agent 跑 21 小时发现新酶：这不是‘AI 发明 CRISPR’

受众：AI 科普、生命科学、科研工具与深度内容读者

角度：沿着 20 万 RT—3500 候选—20 个重点—湿实验这条证据链，区分异常发现、功能假设、实验信号与真正可复现的生物学结论。

结构：1. Agent 做了什么；2. 人类做了什么；3. ART 已知什么；4. 仍未知什么；5. 多 Agent 成本；6. 科研标题核查表。

风险：ART 功能未定、论文为预印本且缺外部复现；标题和正文都不能写成基因编辑工具已经诞生。

选题 04｜A-

企业 Agent 的新控制面：项目记忆、技能商店、沙箱和防注入缺一不可

受众：企业 AI 决策者、Agent 开发者、信息安全与架构类创作者

角度：以 Gemini Enterprise 新栈为例，解释企业为什么不能只买模型，而要同时治理上下文、技能、执行环境、身份和输入安全。

结构：1. Projects；2. Skills Registry；3. Agent Sandbox；4. Model Armor；5. Auth Manager；6. GA 与预览清单。

选题 05｜B+

为什么不能让一群 Agent 直接查询生产数据库？

受众：开发者、数据库从业者、AI 创业者、技术管理者

角度：从 Agent 的突发并发和长推理循环出发，拆解 AlloyDB 隔离只读实例、实时数据、按需缩容和生产负载保护的设计。

结构：1. Agent 查询为何不可预测；2. 生产库风险；3. 隔离实例；4. 数据新鲜度；5. 自动缩零；6. 预览期验证清单。

风险：官方规模与性能数字未经独立复测，产品仍为 preview；需要把架构承诺与真实成本测试分开。
